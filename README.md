# Odunayo Dauda - Personal Portfolio

## Overview
A modern, responsive personal portfolio website showcasing professional projects, skills, and contact information built with Next.js and Tailwind CSS.

## Features
- Responsive design with animated background
- Interactive project showcase
- Dynamic resume/skills section
- Contact form with Formspree integration
- Animated image transitions
- Mobile-friendly navigation

## Technologies Used
- Next.js 14
- React
- TypeScript
- Tailwind CSS
- Formspree
- React Icons
- Heroicons

## Prerequisites
- Node.js (v18 or later)
- npm or yarn

## Installation
1. Clone the repository
```bash
git clone https://github.com/D-o-v/My-Portfolio.git
cd portfolio
```

2. Install dependencies
```bash
npm install
# or
yarn install
```

3. Create a `.env` file and add:
```
NEXT_PUBLIC_FORMSPREE_ENDPOINT=your_formspree_endpoint
```

4. Run the development server
```bash
npm run dev
# or
yarn dev
```

## Deployment
The project is optimized for Vercel deployment. Simply connect your GitHub repository and configure environment variables.

## Customization
- Update personal information in each page component
- Replace images in the `public` folder
- Modify project details in `projects` array
